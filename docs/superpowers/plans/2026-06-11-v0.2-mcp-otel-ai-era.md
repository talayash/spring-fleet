# spring-fleet v0.2 — MCP-first, OTel-native, AI-era Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]` syntax.

**Goal:** Modernize spring-fleet from a 2024-style CLI/script plugin into a 2026-aligned MCP-server-backed, OpenTelemetry-native, AI-augmented debugging plugin for Spring Boot fleets — without breaking the dependency-free Python posture.

**Architecture:**
- New MCP server (`scripts/mcp_server.py`, pure stdlib JSON-RPC over stdio) wraps the existing deterministic scripts as typed tools so Claude calls them deterministically.
- OpenTelemetry W3C `trace_id`/`span_id` become first-class trace keys alongside legacy `sessionId`/`requestId`; logback pattern emits them; correlator recognizes 32-hex.
- New `hooks/session_start.py` injects fleet topology into Claude's context at session start.
- `scan_repos.py` learns Spring Boot 4 / Java 21+ / virtual-threads / GraalVM-native / `compose.yaml` / Testcontainers `@ServiceConnection` / `catalog-info.yaml`.
- New `/impact` and `/run` commands. `/debug` accepts vision input. `log-correlator` outputs Sentry-Seer-style code-grounded RCA.
- New `output-styles/fleet-narrator.md`, `statusline.py`, `hooks/subagent_stop.py`. K8s mode (mirrord/kubectl).
- Distribution: keywords refreshed, version → 0.2.0, GitHub Actions CI for tests + manifest validation.

**Tech Stack:** Python 3.8+ stdlib only · Markdown · JSON Schema draft-07 · MCP (JSON-RPC 2.0 over stdio) · Logback XML · Bash · GitHub Actions YAML.

**Source of truth:** the active TaskList (15 tasks, see `TaskList`).

## Test discipline

Every Python change goes through:
1. Add failing unittest to `tests/test_scripts.py` (or new `tests/test_mcp.py`, `tests/test_hooks.py`).
2. Run `python -m unittest discover -s tests -v` and confirm FAIL.
3. Implement minimal change.
4. Re-run, confirm PASS plus no regression.
5. Commit.

Prompt/agent/skill changes don't have unit tests — but every command/skill change must keep the bundled `fixtures/` demo working (`python scripts/correlate_logs.py --config fixtures/fleet.config.json --value ABC123`).
